- Agent runs can keep keyed digests of the content they drop: with the new setting `privacy.inputDigests` (off by default), a step stored at the `metadata` level keeps an HMAC-SHA-256 digest, keyed with the installation's encryption key, of each message sent, the answer, a tool's arguments and result, and the request a model call answered. Two runs then show which input differed without the text being stored; the run timeline shows the digests shortened. A reader of the run can confirm a guessed short or predictable input, which the setting's label and the data-retention page state. No other level keeps digests (ADR-323).
- `CompletionRequestIdentity` covers requests with tool calls and provider items, and the tool-call terminal attaches the identity of the request it sent. Every identity that existed keeps its bytes (ADR-323).
