- **Choosing a model in the model form no longer unticks capabilities nobody denied.** "Fetch Models" ticked exactly the capabilities discovery reported and unticked the rest. For a model neither the provider nor the built-in catalogue describes — an OpenAI model the catalogue does not list yet, every Groq model, an Ollama host that reports no capabilities — discovery reports `chat` alone, so re-picking such a model silently removed `tools`, `vision` and `streaming` from a record that had them. Readers of the record then treated a tool-calling model as one without tools. Discovery now marks such a list as inferred, and the form only adds to the ticks for it; a list the provider or the catalogue states still replaces them.
