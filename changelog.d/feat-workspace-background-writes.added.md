- The fill of an empty field after a save (ADR-237) works in a draft workspace: the run records the workspace, reads the record and its page as that workspace shows them, and writes a version there through the DataHandler, wherever the editor works when the worker runs; a table without workspace versions is not filled from a draft. A background batch started from the module in a draft workspace reads its scope there — the tree, the empty fields and the page text — and its runs record the workspace; `nrllm:editor-action:batch` runs in live whatever workspace its user last worked in (ADR-265).
