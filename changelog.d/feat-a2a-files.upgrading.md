- Run the database analyzer: the A2A file store adds the table `tx_nrllm_a2a_file` and the column `tx_nrllm_a2a_task.input_manifest`. Nothing changes until `a2a.files.enabled` is switched on; with it off the server still accepts `text/plain` text only and the agent card lists `text/plain` for every skill. The input modes of an A2A publication profile are now a choice of five media types instead of a read-only field; existing profiles keep `text/plain`. While files are on, the largest A2A request grows by the base64 size of `a2a.maxRawPartBytes` (6.7 MiB at the default); check the body size limit of every proxy and of PHP (`post_max_size`) in front of the endpoint.
