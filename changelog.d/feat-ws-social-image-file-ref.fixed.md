- `attach_file_to_content_element` and `attach_file_to_record` no longer discard an editor's earlier draft when they take a failed write back in a draft workspace. Before, discarding the version the call made also discarded the drafts of the record's references that were there before the call, such as an alternative text, and the answer still said the workspace was as it was. The take-back now discards only the rows the call made, and names each row that is not as it was before (ADR-272).
