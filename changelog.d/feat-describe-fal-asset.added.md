- `describe_fal_asset`, a read tool in the `files` group that non-admins may use: it returns the title, alternative text, description, width and height of one file inside the acting user's file mounts, plus copyright, creator, source, publisher and language where EXT:filemetadata is installed. A field the user holds no field permission for reads "withheld", an empty one "not set"; a file outside the mounts and a missing uid get the same answer. `read_fal_asset_meta` stays admin-only (ADR-303).
