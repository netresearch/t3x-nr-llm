- The comment of the site set `netresearch/nr-llm` and the A2A server page no longer say the site settings are read whether or not a site depends on the set. Without the set, `settings.yaml` is read only in the nested form; a dotted key such as `nrllm.a2a.baseUrl` is stored with its dots escaped and is not read, so a site that writes dotted keys has to depend on the set.
