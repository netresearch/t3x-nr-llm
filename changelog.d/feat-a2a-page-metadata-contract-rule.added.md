- Invocation rules `page_metadata_contract` and `page_metadata_read_first` (ADR-297, spec 055 PC1 to PC6): a write of the A2A page metadata skill must set only the requested fields, within fixed lengths, on a row unchanged since the task was accepted, or it is refused before its approval; a write without an earlier read of the page is refused when it runs. Both refusals are logged as `invocation_denied`.
