- Agent runs record the skill versions each model call carried, as a `skill_usage` step before the call: skill and source uid, version digest, identifier, role (instruction, process, context), inclusion (composed, loaded, carried) and the approval that held. A load is recorded as loaded and, at the next call, as passed; a skill that is only attached or only offered for loading is not recorded. The record holds no skill text, is kept at every privacy level after the run ends, and shows in the run timeline (ADR-321).
- `RunTrace::recordSkillUsage()` (`@api`, additive): the step the loop records the skill usage with (ADR-321).
