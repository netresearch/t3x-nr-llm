- Site settings `nrllm.configuration` and `nrllm.deepl.apiKeyIdentifier` in the new site set `netresearch/nr-llm`: a site names the LLM configuration its `chat()`, `complete()` and `streamChat()` calls use instead of the installation default, and the nr-vault identifier of the DeepL key its translations and glossaries use. A named configuration or key that cannot be used fails the call instead of falling back (ADR-244).
- `AbstractOptions::withSite()` and `getSite()` for every option type, moved up from `TranslationOptions`; the site reaches the metadata key the term list check reads. `ConfigurationResolver::resolveForSite()` returns the configuration a site names. `DeepLTranslator::forSite()` returns the translator bound to the site's key. A subclass of an option class that declares its own `$site` property or `withSite()` method must match the new declarations.
- `DocumentAnalysisService` takes an optional `ConfigurationResolver` and probes the document capability of the configuration the call's site names, the one `chat()` then sends to.
- A tool run that pauses for an approval or an input keeps its site when it resumes.
