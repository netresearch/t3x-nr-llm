- **Optional revision of a DeepL translation by a language model (ADR-233).** `TranslationOptions::withPolish(bool $enabled = true, ?string $instruction = null)` asks `TranslationService::translateWithTranslator()` and `translateBatchWithTranslator()` to let a language model revise the result for fluency, terminology and tone when the translator that ran is not the LLM translator. The revision runs on the default configuration or the pinned provider and model, through the budget pre-flight, and is recorded as a `translation_polish` usage row with the caller's extension, which never counts as a request, next to its chat row with the tokens and cost. After DeepL, whose row already counted the request for the same user, the chat call does not count either and the new `ChatOptions::withRequestAlreadyCounted()` makes `BudgetMiddleware` ask `BudgetService` without the extra request against the user's per-day and per-month request limits, so a translation that just fit them is still revised; a configuration's per-day request cap still counts the revision, because DeepL's row is not part of the configuration's usage, and token and cost limits apply as usual. After any other non-LLM translator the revision is an ordinary request. It keeps tags (in order), placeholders and glossary terms: when the answer changes them, starts with a code fence or a preamble, adds lines, is empty or cut off, or the call fails or is refused by the budget, the first translation is returned and `metadata['polish']['reason']` says why — the translation never fails because of the revision. `TranslatorResult::isPolished()` reports whether it applied; `translator` stays the first-pass translator. With `withCacheTtl()`, a requested revision is part of the cache key and a result whose revision did not apply is not stored. The instruction goes into the system message and must come from the calling code, never from editor input. Off by default. `TranslationService`'s constructor gains an optional trailing `TranslationPolisher`; positional callers are unaffected.
