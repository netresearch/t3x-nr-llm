- A write the assistant made is no longer reported as refused because TYPO3 logged an error about another record of the same save. An installation's DataHandler hook that writes another page along with the record (core then logs "Attempt to modify record pages:170 without permission or non-existing page") turned a page description stored as a draft into "TYPO3 refused the change, nothing was changed". Every writer now reads the record back first and reports what took as written with "TYPO3 also reported: …"; a write of which nothing is left is answered as failed, naming what did not take and then TYPO3's messages. The creating writers no longer leave a record behind under "refused", `copy_record` no longer takes back a copy that landed as asked, and `update_fal_asset_meta` reports a call where some fields took as written in part.
