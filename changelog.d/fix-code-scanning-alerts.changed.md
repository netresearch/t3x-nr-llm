- **The A2A interop partner image locks its packages** (`Build/a2a-interop`): a2a-sdk 1.3.0 and uvicorn 0.54.0 move from a `pip install` with version pins into `pyproject.toml` and `uv.lock`, and the image installs with `uv sync --locked`, which checks every wheel against its sha256 and refuses source distributions, as the decision and reranker sidecars do. The python base images of the interop partner and the A2A TCK are pinned by digest. Renovate leaves a2a-sdk, uvicorn and the partner's Python 3.12 alone, because the interop job measures nr-llm against that release and the lock is resolved for 3.12.
