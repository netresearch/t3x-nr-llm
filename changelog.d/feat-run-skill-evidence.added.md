- Skill versions now carry their test evidence: an evaluation stores which skill versions the default configuration composed into every prompt's request (skill, source, digest, role), the configuration and the grading protocol version. When an agent run's model call first carries a version in its segment, the run records the evaluations stored at that moment that measured exactly that digest (at most three, newest first) as a `skill_evidence` step, each marked `match`, `other_model` or `unknown` against the model that answered. A version no evaluation measured is recorded with no evidence. The run timeline shows the recorded snapshot and marks a purged evaluation as `report=gone`. Evaluations run one-shot completions, so a skill loaded on demand is never covered and names no evidence. A lookup that fails is logged and records no evidence step; it does not stop the run (ADR-322).
- `RunTrace::recordSkillEvidence()` (`@api`, additive): the step the loop records the evidence with (ADR-322).
