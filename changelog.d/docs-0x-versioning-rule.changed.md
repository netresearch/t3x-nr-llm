- During 0.x the middle version number rises only for a breaking change: a breaking diff of the frozen `@api` surface or a behaviour change consumers have to handle, marked by a CHANGELOG bullet that opens with `**BREAKING`. Features, fixes and additive database changes raise only the last number, so `^0.55` keeps admitting them and dependent extensions no longer have to widen their constraint for every release. `composer ci:test:changelog:sections` refuses a release whose middle number disagrees with its `**BREAKING` bullets ([Stability](Documentation/Api/Stability.rst)).
