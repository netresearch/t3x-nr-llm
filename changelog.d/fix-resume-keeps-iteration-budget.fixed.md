- A resumed segment keeps the round cap its run was started with. `AgentRunRequest::$maxIterations` applied to the first segment only: `approve()` and `submitInput()` passed no cap, so every segment after an approval or an answered input ran on the loop default of 5, whatever the caller had asked for. The cap is now kept in the suspended state (the `suspended_state` JSON, no schema change), carried across a re-suspension, and clamped to `AgentRuntime::MAX_ITERATIONS` again on resume. A run that asked for no cap, and a run suspended before this release, resume on the loop default as before.
