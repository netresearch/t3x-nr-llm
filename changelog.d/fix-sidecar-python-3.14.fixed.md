- **The decision and reranker sidecar images build again.** Since the base image moved to `python:3.15-slim` (#1147), both builds stopped at the dependency install: the images install their locked packages as wheels only, and markupsafe 3.0.3 and PyYAML 6.0.3 publish none for Python 3.15. Both Dockerfiles are back on `python:3.14-slim`, now pinned by digest in both, and a Renovate rule keeps them below 3.15 until every locked package ships a cp315 wheel. The `Decision Sidecar` and `Reranker Sidecar` workflows now also build the image (without pushing it) when a pull request changes the sidecar, so such an update can no longer merge green.
