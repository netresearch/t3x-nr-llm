- `AfterAiRecordWrittenEvent` names workspace 0 for a write to a table whose TCA is loaded and keeps no workspace versions (no `ctrl.versioningWS`), whatever workspace the acting user wrote from: such a table has only its live row. The writes artifact of an A2A task reads the event and so names an adopted `sys_file` as live. No writer before `adopt_client_file` wrote such a table from a draft workspace.
- `ToolExecutionContext` carries `approvedPreview`: the preview lines the approver saw for the call that runs now, set by the tool loop only while it carries out an approved call whose preview did not fail (ADR-184). A tool that must do exactly what its card showed reads them; `adopt_client_file` writes under the stored name the card named and no other. A previewing tool whose card names more than its arguments can implement `StoredPreviewVisibilityInterface`; the approvals inbox then decides who sees the stored lines on those lines.
