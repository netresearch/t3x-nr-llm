- **The decision and reranker sidecars declare their dependencies in `pyproject.toml` and lock them in `uv.lock`** (`Build/decision`, `Build/reranker`), replacing `requirements.txt`, the hand-made `requirements.lock` and `check-lock-matches-requirements.sh`. Both images install with `uv sync --locked`, which checks every wheel against the sha256 in `uv.lock` and refuses source distributions; torch still comes from the PyTorch CPU index. Renovate can now regenerate the lock with each update. The lock check is `uv lock --check`, run by `decision-sidecar.yml` and `reranker-sidecar.yml` instead of `composer ci:test:repo`. Every package version and wheel hash is unchanged from the previous locks, including transformers 5.20.1 and sentence-transformers 6.1.0.
