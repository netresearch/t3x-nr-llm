- A configuration can have its texts checked against a rule set by a second, small model (ADR-288). The rule set is the snippets carrying the selected tags, one rule per line; the judging model is a configuration the administrator chooses. Mode `report` delivers the text with a hint that quotes the broken rule and the passage; mode `block` stops it like a term list and quotes both, and also stops it when the check gives no usable answer. Off by default; one call per finished text, timeout capped at 20 seconds. Hints reach callers in `CompletionResponse::$metadata['guardrailHints']` and as the return value of a stream (`GuardrailHint::fromMetadata()`, `GuardrailHint::fromStreamReturn()`); `GuardrailResult::allowWithHints()` and `StreamAnnotatingGuardrailInterface` let other guardrails report the same way. Additive API: `GuardrailResult::allowWithHints()`, the optional `$auditReason` of `GuardrailResult::deny()` (what the governance log stores instead of the editor's sentence), the `GuardrailHint` value object, `StreamAnnotatingGuardrailInterface`, the `RuleJudgeMode` enum and the `ruleJudge*` accessors of `LlmConfiguration`.
