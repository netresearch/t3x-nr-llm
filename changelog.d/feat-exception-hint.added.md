- Error hints for administrators: the backend module *AI > Operation > Error hints* lists the ten newest errors from the TYPO3 log files and asks a model, per entry and on request, for the likely cause and the next step; `nrllm:exception:hint` does the same on the command line. The model receives the exception class, the message with credentials masked and the stack frames without argument values, never source code. The provider's trust zone decides: an external provider is not asked, a privately hosted one gets no message. A hint is labelled a guess unless it points at a frame in the project's own code (ADR-258).
