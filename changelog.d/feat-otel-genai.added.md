- OpenTelemetry tracing and metrics through the vendor-neutral API ([ADR-291](Documentation/Adr/Adr291ModelCallsAreTracedThroughTheOpenTelemetryApi.rst)): a span for every attempt at a model (including streams), every fallback chain, every tool execution and every agent run, plus the metrics `gen_ai.client.operation.duration`, `gen_ai.client.token.usage` and `gen_ai.client.operation.time_to_first_chunk`. Nothing is emitted unless the installation registers an OpenTelemetry SDK; prompts, answers and exception messages are never recorded. The extension setting `telemetry.openTelemetry` switches it off. Requires `open-telemetry/api`.
