- A streamed answer reaches the caller while the provider is still writing it. The seven streaming adapters (OpenAI, Claude, Gemini, Groq, Mistral, Ollama, OpenRouter) sent the request with `sendRequest()`, which on nr-vault's HTTP client returns only once the whole response has arrived, so every chunk reached the generator at the end and an editor saw the complete answer appear at once. They now send it with nr-vault's `sendStreaming()` (nr-vault 1.1), which keeps the DNS pin and reads the body from the wire as it is consumed. A client without streaming support (nr-vault 0.16, a provider without an API key, a client set with `setHttpClient()`) still sends with `sendRequest()`.
