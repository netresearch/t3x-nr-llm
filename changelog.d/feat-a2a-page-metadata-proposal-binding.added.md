- A write of the A2A page metadata skill is bound to the proposal a check judged (ADR-298, spec 056): the new read-only builtin `check_page_metadata` (group `editing`, ships disabled) takes exactly the arguments of `update_page_metadata` and checks them against the task, and the invocation rule `page_metadata_binding` lets the write run only when its arguments are those of the latest passed check and the checked fields of the row are unchanged since (`proposal_not_checked`, `changed_since_check`). It replaces the read-first rule and the `tstamp` comparison. A profile of the skill must now grant `check_page_metadata` as well.
- Public API (ADR-298): `InvocationDigests` computes keyed digests of a call's arguments and of a record state, `ObservedState` carries such a state, `ToolResult::withObservedState()` and `ToolResult::$observedState` report one, and `ToolInvocationHistory::append()` takes two optional digests that an entry stores as `arguments` and `state`. Stored histories without them keep loading.
