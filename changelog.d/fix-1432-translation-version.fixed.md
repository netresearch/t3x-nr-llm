- The `writes` artifact of an A2A task now also names the records a completed tool call wrote beside its announced write, in a block of its own. With AI Label installed, a page metadata write to a page with a translation left a workspace version of the translation that no list named: AI Label stores its metadata on the page's draft after the call, and core gives the translations a version in that write, as it does when an editor saves the page in a workspace. The changes the listeners of a write store are now part of the call's `tool_changes` step, and the page metadata skill's documentation no longer says that translations stay without a draft (ADR-295).
- The change list of a tool call (`tool_changes`) names a move in a draft workspace as the version it wrote, in that workspace. It also listed the live record as moved in workspace 0, although live was not changed, and the `writes` artifact of an A2A task would have shown that line (ADR-292, ADR-295).
