- A write to a page or record with a translation, under the scope of an assignment that admits the default language only, is no longer an error. Core adds an entry for every translation to each such write, with the fields it keeps equal in all languages; the scope refused that entry, so the A2A page metadata skill reported a description of a translated page as not saved while its draft was stored. The entry is now left out when the run's write changes none of those fields, and the translations stay as they are. A write that does change such a field needs the languages of all translations in scope (ADR-295).
- The `writes` artifact of an A2A task also lists, in a block of its own, the records a tool call that ended in an error changed all the same, for example the in-scope part of a call the scope partly refused. It said "No write was executed." beside a stored draft (ADR-295).
