- The A2A tokens module shows a revoked or switched-off technical client as disabled and offers "Enable and generate token" in place of "Generate token": a token for a disabled client was issued all the same and answered `401`. Issuing never enables a record by itself; the server refuses a token for a disabled record unless the administrator confirms the enabling, which needs a usable technical backend user (as the Enabled field does) and is logged in the token audit like the other actions. `nrllm:a2a:client:token` warns on stderr when it issues a token for a disabled record (ADR-294).
