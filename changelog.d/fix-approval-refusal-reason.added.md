- `ApproverNotPermittedException` tells callers why an approval was refused: `getCause()` returns an `ApprovalRefusalCause` (a denied tool, an approver without backend permissions, an unreadable pending call), and `getDenialReason()` returns the tool policy's `ToolDenialReason` for a denied tool, so a surface can say that a tool has been switched off instead of blaming the approver's permissions (#1179).
