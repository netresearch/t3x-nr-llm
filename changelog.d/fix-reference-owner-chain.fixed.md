- **`set_file_reference_alternative_text`, `attach_file_to_record` and `replace_file_reference` ask about every record that holds an inline child (ADR-230).** A file reference on an inline child record, such as a carousel item inside a content element, or a content element held by another record the way EXT:news holds content elements, was authorised against the child record and its page only, so an editor could set its alternative text, attach a file to it or replace its file while the outer record had an edit lock, was of a content type outside their `authMode` grant, or sat on a page they may not edit. The three tools now walk the inline owners up the chain and ask each the same table, page and record-level questions, with each tool's neutral refusal; an inline child whose owner is gone is refused too. `ReplaceFileReferenceTool` takes `TableReadAccessService` as a fourth constructor argument; the container wires it.
