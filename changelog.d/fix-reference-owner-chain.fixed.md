- **`set_file_reference_alternative_text` asks about every record that holds an inline child (ADR-230).** A reference on an inline child record, such as a carousel item inside a content element, was authorised against the child record and its page only, so an editor could set its alternative text while the outer content element had an edit lock, was of a content type outside their `authMode` grant, or sat on a page they may not edit. The tool now walks the inline owners up the chain and asks each the same table, page and record-level questions, with the same neutral refusal; an inline child whose owner is gone is refused too.
