- **A model record can carry its reasoning profile, so a new OpenAI model works without a release (ADR-274).** Three optional fields on the model record set whether it is a reasoning model, which `reasoning_effort` values it accepts and whether tool calls go through Chat Completions or Responses; each wins over the bundled table, a discovered profile and the family default. *Confirm capabilities* records the reasoning flag and effort scale OpenRouter states for a model on an OpenRouter provider, and, with the new extension setting `discovery.thirdPartyReasoningCatalog` (off by default), the reasoning flag OpenRouter's public list states for a model on an OpenAI provider, marked with the new `CapabilitySource::ThirdPartyCatalog`. The OpenAI adapter, the output ceiling and the configuration form's parameter constraints use the resolved profile, and the model list shows the resolved reasoning flag with its source. Existing records keep their behaviour: all new fields default to empty.
