- `create_content_element_draft` drafts a content element with its child records: the items of an accordion, card group, icon group, tab, timeline or carousel are passed as `children` and written with the element in one DataHandler call, listed on the approval card and read back. A FlexForm column is written with its data structure's defaults, folder, group and record-backed select columns are left empty instead of excluding the type, and `link` columns become fillable with `http`, `https`, `mailto`, `tel` and page links (ADR-324). On a bootstrap_package site this offers accordion, card group, icon group, tab, timeline, the carousels, text with image, image, media, gallery and uploads.
- `ContentElementComposer` (`@api`) exposes the same content-type rule to other extensions: `describe()` a type as a model reads it, `typesOfferedOnPage()` for a page's `TCEFORM.tt_content.CType` rules and a user's grants, and `dataMap()` for one element with its child records after every value and grant was checked (ADR-324).
