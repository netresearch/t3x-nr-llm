=============================
Architecture decision records
=============================

.. _architecture-decision-records:

Start with the current guides for implementation and operations:
:ref:`api-agent-runtime`,
:ref:`api-tool-extensions`,
:ref:`administration-skills`,
:ref:`administration-governance` and
:ref:`routing-reference`.

An ADR explains why a decision was made. Check its status and amendment links
before treating historical examples as current instructions. Accepted records
can have amended sections; proposed records are not settled contracts.
