# Relations

* [uses](uses.md) - The source needs the target to do its work.
* [fallsBackTo](fallsBackTo.md) - The source hands its work to the target when the source fails.
* [constrainedBy](constrainedBy.md) - The target limits or checks what the source may do.
* [partOf](partOf.md) - The source is a component of the target.
* [derivedFrom](derivedFrom.md) - The source is produced from the target.
* [approves](approves.md) - The source records the consent of a person to one version of the target.
* [records](records.md) - The source is a log of what the target did.
* [implementedBy](implementedBy.md) - The target is the code that realizes the source.
* [verifiedBy](verifiedBy.md) - The target is a test that checks the source.
