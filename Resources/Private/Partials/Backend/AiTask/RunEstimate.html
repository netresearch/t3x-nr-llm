What one run of the task is expected to cost and whether the budget lets it start (NEXT-170). Arguments: estimate (TaskCostEstimate), verdict ({state, message}, built in AiTaskController). Prices with four decimals, as the AI actions batch estimate prints them: a single run is often below one cent. TaskExecute.js replaces the verdict after a run; the region is a status live region so the new sentence is announced.

: ~${estimate.costLow -> f:format.number(decimals: 4)} – ~${estimate.costHigh -> f:format.number(decimals: 4)}

{verdict.message}
